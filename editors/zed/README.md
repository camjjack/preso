# preso for Zed

Launches [`preso-lsp`](../../docs/guide/src/getting-started/editor-support.md)
for Markdown files. It gives you a slide outline, problems reported as you
type, completion, and slide and layout code actions for preso decks.

`preso-lsp` comes with preso — `brew install camjjack/preso/preso`, the
release downloads and the `.deb` all install it next to `preso` — and the
extension finds it on your `PATH`. Then run **zed: install dev extension**
and choose this directory.
